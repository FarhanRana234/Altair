- Built using `@react-three/fiber` and `@react-three/drei`.
- Renders 3D model with OrbitControls (auto-rotate enabled with user override).

- Interactive range slider for sponsorship investment (PKR 30,000 to PKR 500,000+).

- Glassmorphic modal popup triggerable from any "Sponsor Us" CTA button.
- Captures name, email, company, target tier, and custom note.

- On successful API response, triggers automatic browser download for `/ALTAIR_SPONSORSHIP_PROPOSAL.pdf` and shows success notification.
